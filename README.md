# 🚀 code.connect

> A modern, responsive developer social hub built to help coders connect, share, and grow. 

**code.connect** is a frontend React application designed with a sleek user interface to facilitate a community-driven platform for developers. This project was conceived and developed as a capstone project during a 45-day frontend web development internship in Mohali.

---

## ✨ Features & Functionalities

Based on the core module architecture, the application currently features:

*   **🔐 Secure Onboarding (Login/Signup):** Dedicated authentication pages (`Login.jsx`, `Signup.jsx`) with custom CSS styling for a smooth user onboarding experience.
*   **👤 Developer Profiles:** A dynamic `Profile.jsx` dashboard where users can showcase their coding journey, projects, and bio.
*   **⚙️ Account Management:** A `Settings.jsx` interface allowing users to customize their application preferences and account details.
*   **🧭 Intuitive Navigation:** 
    *   **Sidebar Dashboard:** A persistent `Dashboardsidebar.jsx` for quick access to core platform features.
    *   **Navbar & Footer:** Fully responsive structural components (`Navbar.jsx`, `Footer.jsx`).
*   **🛣️ Dynamic Routing:** Client-side routing implemented via React Router DOM for seamless, reload-free page transitions across the hub.
*   **⚡ Lightning Fast Build:** Powered by Vite for instant Hot Module Replacement (HMR) during development.

---

## 🛠️ Tech Stack

*   **Frontend Framework:** [React.js](https://reactjs.org/)
*   **Routing:** React Router DOM
*   **Build Tool:** [Vite](https://vitejs.dev/)
*   **Styling:** Custom CSS3 (Modular component-level styling)
*   **Icons:** Lucide-React
*   **Linting:** ESLint
*   **Package Manager:** npm

## 🚀 Getting Started

To run this project locally on your machine, follow these steps:

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) and Git installed on your system.

### Installation

1. **Clone the repository:**
```bash
git clone [https://github.com/Missruhani/code.connect--app.git](https://github.com/Missruhani/code.connect--app.git)

```


2. **Navigate into the project directory:**
```bash
cd "code.connect app"

```


3. **Install the dependencies:**
```bash
npm install

```


4. **Start the development server:**
```bash
npm run dev

```


5. **Open your browser:**
Navigate to the `localhost` URL provided in your terminal (usually `http://localhost:5173/`).
